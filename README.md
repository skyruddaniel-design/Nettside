# Portefoljenettside

Dette er en statisk, responsiv portefoljenettside for et innholdsproduksjonsselskap.

## Slik åpner du siden i VS Code

1. Åpne denne mappen i VS Code.
2. Åpne `index.html`.
3. Høyreklikk i filen og velg `Open with Live Server` hvis du har Live Server-utvidelsen.

Du kan også åpne `index.html` direkte i nettleseren uten å installere noe.

## Bytt bakgrunnsvideo

Legg din egen video i mappen `assets` og kall filen:

```text
hero-video.mp4
```

Videoen bør være kort, uten lyd, og komprimert for web. Anbefalt størrelse er 1920x1080 eller 1280x720.

Hvis `assets/hero-video.mp4` ikke finnes, bruker siden en ekstern eksempelvideo som midlertidig bakgrunn.

## Tilpass innhold

Endre firmanavn, tekster, e-post, telefonnummer og porteføljecaser direkte i `index.html`.
